# Secure P2P File Transfer (Expo / React Native)

تطبيق إرسال واستلام ملفات آمن وسريع عبر شبكة Wi-Fi المحلية/P2P وBluetooth دون الحاجة لاتصال إنترنت خارجي.

## المميزات
- **نقل P2P مباشر:** يعتمد على WebRTC DataChannels.
- **تشفير اختياري:** تشفير التشانكات بـ AES-256 أثناء النقل.
- **سلامة البيانات:** التأكد من سلامة الملف النهائي بواسطة SHA-256.
- **دعم أندرويد الحديث:** متوافق بالكامل مع Android 11 و 12 و 13 و 14+.

## متطلبات التشغيل
- Node.js LTS v20+
- Expo CLI (`npm i -g eas-cli`)
- جهاز أندرويد حقيقي لاختبار ميزات البلوتوث والشبكة المحلية.
