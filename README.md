# ShareIt Clone - React Native (Expo)

تطبيق نقل ملفات موجه للأجهزة الذكية مستوحى من SHAREit يعتمد على نقل الملفات المباشر عبر الشبكة المحلية (Local Wi-Fi Network).

## المميزات
- نقل مباشر بدون الحاجة لاتصال بالإنترنت.
- توليد رمز QR لربط أجهزة الإرسال والاستلام بسهولة.
- دعم اختيار كافة أنواع الملفات من ذاكرة الجهاز.

## متطلبات التشغيل
- Node.js مثبت على الجهاز.
- تطبيق Expo Go على الهاتف المحمول (Android / iOS).
